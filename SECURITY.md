# Security policy

## Supported versions

Security fixes are applied to the latest released version of `@kz-rush/site-ui`. Consumers should upgrade to the latest version before reporting an issue that may already be resolved.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. If private reporting is not available, contact the maintainer using the address in `package.json` and include "Security: site-ui" in the subject.

Do not open a public issue or discussion containing exploit details, credentials, personal data, or other sensitive information.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within seven days. Please allow a reasonable period for investigation and remediation before public disclosure.

## Scope

Reports concerning this library's source code, published package, build pipeline, or release process are in scope. Vulnerabilities in downstream applications should be reported to their respective maintainers.
